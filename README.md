# Kodik Downloader

Простой инструмент для загрузки видео из плеера Kodik.

## Возможности
- Сбор всех доступных качеств (360p-1080p).
- Принудительное HD (Force HD).
- Интерфейс на RU, EN, UK.
- Выбор папки через проводник.

## Требования
- Python 3.8+
- Chromium (ставится сам при запуске).
- Желательно наличие Chrome в системе.

## Запуск
Просто запустите `run.bat`. Он сам поставит зависимости и откроет меню.

## Совместимость
Работает только с плеером Kodik. Проверено на YummyAnime и AnimeGo.
